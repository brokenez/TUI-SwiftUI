# Checkicon: соответствие импортированной матрице

Проверено 5 октября 2026 по сохранённым метаданным TUI Mobile и текущему публичному API. Это проверка сопоставления вариантов; свежая визуальная приёмка не выполнена. Попытка обновить design context набора через Figma завершилась HTTP 403. После этого три варианта, свойства экземпляра и два текстовых слоя прочитаны через панель Properties приложения Figma; факты сохранены в source-inspection-2026-10-05.json. Полная спецификация и runtime-сравнение этим не заменяются.
