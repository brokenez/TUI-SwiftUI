## Особенность исходных свойств

У варианта `18083:44906` в Figma отсутствуют componentPropertyReferences title, description и Accessory. Поэтому значение свойства экземпляра не доказывает фактический контент этого варианта. При сборке экрана необходимо читать characters текстовых слоёв и visibility Accessory. API позволяет настраивать этот контент согласно спецификации; это не утверждение о восстановлении отсутствующих привязок Figma. В остальных девяти вариантах привязки подтверждены `property-references-2026-10-06.json`.
