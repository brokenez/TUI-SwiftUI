# Header Large: визуальная приёмка исходной матрицы

Источник — десять применимых iOS-вариантов набора `42565:305012`. PNG получены непосредственно из Figma в 3x, без реконструкции. Нативные PNG — исполнение `TUIHeaderLarge` через ImageRenderer, iPhone 17 / iOS 26.4.1, стандартный размер текста, без анимации skeleton. Текущий пакет прошёл 64 теста; standalone-каталог и отдельный потребитель собраны и проверены.

## Решение

Исходная матрица визуально принята. Для каждого node ID сохранены оригинал и нативный рендер. Размеры, отступы, line boxes, базовые строки, шрифтовые лица, tracking, цвета и композиция совпадают с исходными метриками. Это не утверждение о побитовом равенстве PNG: остаточные отличия растеризации текста сохраняются и описаны ниже. Значения шрифтов или spacing ради подгонки изображения не менялись.

Контактный лист просмотрен целиком; отдельно просмотрены многострочный слот, native inline-symbol и Night. Численные проверки дополняют просмотр, не заменяют его. Итоговые пары и статистика — `Validation/2026-10-06/HeaderLargeModernSlotsComparison3x/comparison.json`; исполняемые оригиналы — `HeaderLargeModernSlotsNative/manifest.json`.

## Измеренные отличия

- Все десять размеров совпали: 375×104 pt с description, 375×102 pt с subheader. Title line box — 36, description — 20, subheader — 18; padding 8/16/24/16 и вертикальный gap 16.
- Skeleton: максимальная разница RGB 1/255 для start и 5/255 для center, средняя до 0.0018/255. Отличия на сглаженных границах; геометрия совпадает.
- Текст: средняя абсолютная разница RGB до 0.541/255; до 0.708% пикселей отличаются больше чем на 16. Максимальная локальная разница 203/255 относится к контурам, поэтому сама по себе средняя разница не использована как порог приёмки.
- Границы плотного title ink имеют одинаковые top/bottom и left. У четырёх leading-вариантов край справа отличается на 1 пиксель в 3x; у center границы совпали. Bidirectional-проверка foreground показала отсутствие выходов за однопиксельную окрестность в восьми вариантах; у двух center-вариантов обнаружено по одному пограничному пикселю. Полные данные — `contour-envelope.json`. Маски не сдвигались, цвет не корректировался.
- Исходные SVG-контуры и нативные PDF подтверждают SF Pro Display Bold / SF Pro Text Regular и baseline 37/76 для description, 37/74 для subheader. Контуры шрифтов проверены с исходными файлами. Небольшое различие растеризации принято как различие Figma/Core Text при совпадающих шрифте, базовых строках и исходном tracking, а не как разрешение менять метрики компонента.

## Тема и дополнительные состояния

Свежий `get_variable_defs` extended-варианта подтвердил Text/Primary #333333, Text/Secondary #9299a2 и Neutral 1 On Light black alpha 3%. Нативные Day/Night text ink сверены с Foundation Theme modes: 18 проверок совпали. Night Primary — #f6f7f8, Secondary — #9299a2. Результат — `header-large-modern-slots-token-audit.json` с контрольной суммой исходного Foundation snapshot. Это проверка нативных цветов по токенам, не экспорт отдельного Night-скриншота Figma. Декоративный guide-placeholder On Light сохраняет alpha 3% black в обеих темах.

Нативный пакет дополнительно подтвердил: скрытый subheader (68 pt), source avatar 36 pt с точным PDF, переносы текста, single-line fade и сохранение suffix, пять выравниваний многострочных слотов, inline-символ в последней строке, AX1 reflow/cap. Extended placeholders теперь центрируются по всей высоте label, как `self-stretch/items-center` в свежем контексте `extended-recheck-2026-10-06.txt`. Accessory выравнивается отдельно по первой строке. Описание при AX1 располагается перед accessory; нативный UI подтвердил порядок и отступ без пересечений.

## Незакрытая область

Полный статус набора остаётся `in-progress`. Ещё нужна окончательная приёмка остальных ограничений и кастомизаций из спецификации, а также доступности, включая focus bounds single-line fade и встроенные ссылки скринридера. Визуальная приёмка десяти исходных вариантов не означает завершение этих проверок или всего набора.
