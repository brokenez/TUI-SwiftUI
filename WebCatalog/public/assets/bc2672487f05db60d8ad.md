# Header Card — реализация и проверка 7 октября

Набор `44217:298609`, девять фактических iOS-вариантов. Публичный `TUIHeaderCard.Variant` сохраняет ID и точные свойства `System`, `Accessory`, `Extended`, `skeleton`. API сохраняет HeaderText, SubheaderText, Subheader, Description, Caption, CaptionText, Badge и Hint. Слотам расширенного подзаголовка потребитель передаёт собственные View; редакторские placeholder-инстансы не становятся обязательным интерфейсом приложения.

Размеры: верх 16, низ 12, слева 20; справа 20 для None/Link и 16 для Avatar/Button/Switch/skeleton. Между текстовыми блоками 8. Заголовок 20/24, tracking +0.38; подзаголовок 15/18, tracking −0.24 и дополнительный отступ 2; описание 17/20, tracking −0.41. Caption 13/16 помещён в исходный контейнер высотой 12, uppercase, single-line fade. Использованы TUIColor/TUISpacing, исходные legacy-метрики и общий рендерер текста Header. Современные роли Foundation не подменяют отличающиеся от них legacy-стили молча.

Button/Link требуют обработчик потребителя; Switch требует writable Binding. Действия не исполняются при отрисовке. Switch — TUISystemSwitch на iOS 26. Аватар декоративный; badge скрыт от отдельного фокуса, родитель сообщает полный счётчик, включая отображаемое 99+. Hint доступен как дополнительное действие заголовка. Переполнение, ссылки в AttributedString, переносы, fade, собственные слоты и opt-in reflow accessory на AX1 используют общий текстовый механизм. Размер Dynamic Type ограничен AX1; AX5 даёт ту же геометрию. Это не утверждение о завершённой доступности: полная семантическая проверка ещё нужна.

Проверено: четыре новых теста Header Card и 15 регрессионных Header Large прошли на iOS 26.4.1; реальные размеры восьми чистых SwiftUI-вариантов совпали с 375×80/100 pt в двух темах. Два UI-теста приложения подтвердили Button, Button Link, изменение состояния native Switch без вызова чужого действия и чистые снимки переключателя в двух темах. Тестовый хост не использует List. Прямоугольник реального native view `(0,182,375,80)` захвачен из экрана как `(0,546,1125,240)` пикселей без изменения размеров или цветов; provenance приложен. Нативный переключатель снимается в приложении: ImageRenderer возвращает для UIKit-контрола предупреждающий значок, а тесты пакета не имеют активной UIWindowScene. Первая попытка и снимки со скруглением List не публикуются как актуальный предпросмотр. В попытке захвата из строки List четыре строгих пиксельных проверки выявили неподходящую оболочку; это исправлено отдельным native host, а не подгонкой изображения.

При сравнении обнаружен дефект малого TUIButton: отсутствовали 7 pt с каждой стороны контейнера сверх padding label. Исправлены только эти отступы; подтверждение — исходники small Primary в Header Card и свежие контексты small Flat/Glass. Точное соответствие шрифта вложенной кнопки остаётся открытым. Наличие полного Button API не означает приёмку всех 147 вариантов.

Общие рендереры Header Large получили внутреннюю доступность без изменения layout/рисования. Все 42 PNG, сопоставленные с принятой матрицей Header Large, пиксельно идентичны; отчёт `Documentation/Validation/2026-10-07/HeaderCardFinalNative/header-large-regression.json`. Поэтому это локальное обновление зависимости с сохранением прежних доказательств, а не повторное назначение всех статусов.

Примеры веб-каталога проверены компиляцией: 109 уникальных примеров, включая все девять вариантов Header Card; результат `Documentation/Validation/2026-10-07/WebCatalog/header-card-example-summary.json`. Нативные снимки восьми чистых SwiftUI-вариантов и UIKit Switch опубликованы в двух темах. Тема берётся из доказательства, а не имени вложения; соответствие исходному файлу каждой темы проверяется. В браузере Night Switch загрузился, скопированный пример совпал с показанным кодом. Независимая интеграция и сопоставление теперь приняты: [девять вариантов и проверка в потребителе](consumer-acceptance-2026-10-07.md). Это не заменяет оставшиеся пять проверок.

Незакрыто:

- Caption использует системный SF Pro Medium вместо исходного статического SF Pro Text Medium; измеренное/визуальное совпадение не заявлено. Решение о распространяемых шрифтах остаётся отдельным открытым пунктом библиотеки.
- Полная сверка specification, child states, animations, AX-фокусов и дополнительных действий ещё не завершена.
- Визуальная проверка всех вариантов не принята. iOS 26 Switch намеренно имеет системный вид; исходная вложенная иллюстрация переключателя историческая. Эта разница должна быть явно сопоставлена с утверждённой политикой iOS 26.
- Extended без переданных consumer slots отличается от редакторских placeholder-инстансов исходного компонента. Веб-снимок показывает реальный экземпляр без этих слотов; изображения/код не маскируются под полный исходный состав.

Header Card остаётся `in-progress`. Вся система не завершена.
