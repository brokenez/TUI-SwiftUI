# Floating Button: исправление внешней тени

В публичном `TUIButton` исправлено преобразование Figma Blur в SwiftUI shadow radius. Значение Small Blur из токенов сохраняется: 20 в Day, 0 в Night; renderer использует половину этого значения. Публичный API, остальные оформления, цвета, размеры, подписи и взаимодействия не изменены.

До изменения прочитаны полное доступное руководство [Button](../../../References/Button/source-review-followup-2026-10-08.md), [Foundations / Тени, 2872:5946](https://www.figma.com/design/gGt4PaQxQhX7ozPVImsgL5/TUI-Foundations?node-id=2872-5946) с диаграммами, исходная матрица эффектов и свежие design contexts трёх нормальных iOS Floating вариантов: [Large 49513:311416](https://www.figma.com/design/OBPLqL8JDThLuOP8M4JzBL/TUI-Mobile?node-id=49513-311416), [Medium 49513:311400](https://www.figma.com/design/OBPLqL8JDThLuOP8M4JzBL/TUI-Mobile?node-id=49513-311400), [Small 49513:311393](https://www.figma.com/design/OBPLqL8JDThLuOP8M4JzBL/TUI-Mobile?node-id=49513-311393). Все новые ссылки, контексты и полные исходные PNG находятся в `Documentation/References/Button/2026-10-13`. Системные элементы внутри Foundation-иллюстраций не переносились. Figma не редактировалась.

Источники используют Shadow/Small: чёрный с alpha 0,10, Blur 20, X 0, Y 5. В Night тень автоматически выключается. Эмпирическая проверка этого renderer-перевода для Card Large сохранена исторически отдельно; она не подменяла новое сравнение Button. Сначала получены снимки реального Button с прежним radius 20, затем с radius 10. Оба набора сравниваются с одними свежими Figma PNG по полным границам эффекта. Естественный компонент начинается в (20,15); экспорт включает ещё 20 pt слева/справа и 25 pt снизу. Нативный @3x уменьшен LANCZOS и скомпозитирован на белом.

[Полные измерения](comparison.json) и [изображение Figma / до / после](comparison.png) подтверждают уменьшение расхождения внешней тени примерно на 77–78%. Максимальная локальная разница остаётся 16/255: сглаживание контура и остаточные отличия требуют дальнейшей проверки. Эти значения служат диагностикой, не автоматическим критерием `complete`. Три нормальных Night PNG пиксельно идентичны до/после.

Финальный нативный прогон [6 passed, 0 failed](matrix-package-summary.json) на iPhone 17 Pro / iOS 26.4.1 включает всю импортированную Floating-матрицу: **12 вариантов × 2 темы = 24 runtime renders**. У каждого сохранены точный source ID, ширина и высота. Small Loading имеет исходный frame 30 × 30, остальные Small — 57 × 30; источник не исправлялся под обычную intrinsic ширину подписи. Проверяется наличие внешней тени в Day и её отсутствие в Night. Эта серия не проверяет длительность Loader. Дополнительно прошли затухание длинного текста, непрозрачность короткой подписи, Medium Hug/Fill и три skeleton-контура. [Материалы](MatrixNative/manifest.json), [лог](matrix-package-tests.log), [версии исходников](source-versions.json). Отдельный каталог собран с изменённым пакетом: [BUILD SUCCEEDED](catalog-build.log).

В реестре заменены только старые runtime previews двенадцати Floating ID на актуальные 24 изображения; прежние материалы остаются в исторических папках. Три свежих исходных normal Day PNG связаны с соответствующими ID. Чёрные диагностические fade PNG не используются как изображения исходных вариантов. Повторный вывод веб-каталога использует этот же реестр.

Пересобранный веб-каталог проверен с HTTP: [итог](web-http-check.json). Его текущие метаданные и все **24 Floating PNG** отдаются локальным сервером с HTTP 200 и точными SHA-256: [прямая проверка](web-native-http-check.json). Веб содержит 263 варианта с нативными превью, 323 копируемых SwiftUI-примера и 602 проверенных asset-файла; Apple-шрифты туда не копировались. [23 проверки проекта](script-tests.log) прошли, `git diff --check` — без ошибок. Это локальный каталог, публикации не было.

Попарно рассмотрена внешняя тень **трёх normal Day вариантов**. Остальные 21 Floating render, другие Button appearances, ночная визуальная сверка с Figma, typography, Glass, кастомные комбинации, взаимодействия и точное legacy motion не объявляются принятыми по этому исправлению. `visual` и полный Button остаются `pending`/`in-progress`. Текущий общий объём — 112 кастомных наборов; 16 системных Apple исключены с сохранением метаданных.
