# Spacing: соответствие импортированной матрице

Проверено 5 октября 2026 по сохранённой матрице TUI Mobile и enum TUISpacingIndicator.Size. Все 21 строки сопоставлены API: для десяти размеров 2…48 есть Visible=on/off; для размера 0 в Figma существует только Visible=on.

Сохраняются исходные значения Size: 0, 01 - 2px, 02 - 4px, 03 - 8px, 04 - 12px, 05 - 16px, 06 - 20px, 07 - 24px, 08 - 32px, 09 - 40px, 10 - 48px. API соответственно использует zero, x2, x4, x8, x12, x16, x20, x24, x32, x40, x48. Visible=on/off соответствует visible=true/false.

Реальный запуск тестов обнаружил пропущенный hidden ID для размера 2 pt: 28406:482305. После чтения его design context (невидимый квадрат размером 2 pt) ID добавлен. Остальные существующие варианты сохранены. Нулевая геометрия и обе видимости по API не означают наличия дополнительного варианта 0/off в Figma.

Тест spacingIndicatorCoversTheImportedFigmaScale проверяет все ID, размеры и свойства матрицы. Последний запуск тестового target завершился кодом 0, но подробный xcresult сейчас недоступен из-за сбоя автоматической проверки разрешений HTTP 403. После добавления @MainActor к этому тесту повторный запуск ещё не подтверждён. Визуальная сверка всех 21 вариантов не выполнена; полный статус complete не присваивается.
