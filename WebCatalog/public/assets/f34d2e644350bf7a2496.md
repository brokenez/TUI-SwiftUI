# Header Large: текущий этап проверки ссылок

Пакет после изменения обработки ссылок: 70 Passed, 0 Failed — `Documentation/Validation/2026-10-06/header-large-link-focus-final-package-summary.json`. Два новых изолированных UI-сценария: 2 Passed, 0 Failed — `Documentation/Validation/2026-10-06/header-large-native-link-focus-ui-summary.json`.

Проверено на iOS 26.4.1 в отдельном приложении-потребителе: нажатие на видимый фрагмент частичной ссылки в последней строке multiline fade вызывает обработчик; нажатие на обычный текст повторно ссылку не открывает. Нативный UIKit accessibility bridge сохраняет полную подпись заголовка, header trait и область 343×108 pt; дополнительное действие «Открыть ссылку: конце» выполняет обработчик. Эти проверки не являются прослушиванием VoiceOver.

Ранее общий UI-прогон имел одну ошибку в утверждении об отсутствии Link в дереве автоматизации XCTest. Такое дерево отличается от представления UIKit для доступности. Причина установлена по нативным элементам, дополнительным действиям и их реальному выполнению; новое утверждение проверяет отсутствие отдельного доступного элемента «конце», а физическое нажатие проверяется независимо. Не выдаём предыдущий неуспешный прогон за Passed.

Изменены исходник Header, вспомогательный TUIHeaderTextLinks, тесты и экран потребителя. Прежние проверки относятся к предыдущему состоянию исходников. Существующие контрольные суммы входов сохранены до итоговой приёмки, чтобы резолвер показывал staleInputs. Изменённые файлы доказательств обновлены как текущие снимки; затронутые interaction, motion и integration переведены в pending. Старые суммы сохранены в previousSha256. Это техническая актуализация реестра, не новая сертификация компонента.

До полной приёмки остаются итоговая сверка требований спецификации, семантика ссылок в обычном заголовке/подзаголовке/описании и подтверждение применимости прежних визуальных и поведенческих доказательств к текущему коду. Непрозрачный вход titleInlineText(Text) не анализируется для выделения URL: поддержка AttributedString не доказывает поддержку произвольной композиции Text со ссылками. Header остаётся in-progress; оба ранее принятых набора Skeleton сохраняют complete.
