# TUI — веб-каталог iOS-библиотеки

Каталог показывает матрицу 112 наборов текущей поставки, реальные нативные рендеры, SwiftUI-код, страницы спецификации, локальные отчёты и записи анимаций. [16 системных наборов Apple исключены](../Documentation/system-components-scope-2026-10-09.md) по решению пользователя от 9 октября; все 128 исходных записей сохранены в репозитории. Это каталог Swift Package, а не библиотека веб-компонентов. Для интерактивного тестирования самого SwiftUI-компонента используется нативное приложение каталога.

## Запуск

Нужны Node.js 20+ и Python 3.9+. Сторонние зависимости отсутствуют.

Из корня репозитория:

```sh
python3 Scripts/generate_component_coverage.py
cd WebCatalog
npm run build
npm run dev
```

Открыть `http://127.0.0.1:4317`. Сервер слушает только локальный интерфейс. В `dist/` находится готовая статическая версия для будущего размещения; публикация не выполняется автоматически.

## Как обновляются данные

`Scripts/generate_web_catalog.py` читает Figma-матрицу, паспорта приёмки, исходники публичных компонентов и сохранённые нативные доказательства. Готовность вычисляется заново, включая контроль входных файлов. Статусы не назначаются веб-интерфейсом.

Нативный рендер и исходный макет Figma имеют разные подписи. Тема переключает сохранённый снимок соответствующей темы; если снимка нет, интерфейс сообщает об этом. Веб не изменяет цвета или шрифты картинки для имитации другой темы.

Примеры использования создаются только для поддержанных публичных API и проверяются компиляцией. Если для варианта нет подтверждённого сопоставления, доступен исходник реализации; готовый пример использования не выдумывается. Текст и состояние реального компонента нельзя менять внутри PNG. Записи анимации запускаются по действию пользователя и поддерживают паузу, перемотку и выбор скорости. Оболочка учитывает `prefers-reduced-motion`.

Для обновления проверочных SwiftUI-примеров выполните `python3 Scripts/generate_web_catalog.py --swift-fixture` из корня. Проверка находится в `WebCatalogExamplesTests` схемы `TUIDesignSystemTests` пространства `PackageTests.xcworkspace`. Последняя проверка: 138 уникальных примеров скомпилировались, включая CardLarge Cell/Cell Flat. Чистые SwiftUI-примеры проверены отрисовкой; Header Card с UIKit Switch проверен в сцене приложения отдельными UI-тестами. История и ограничения — `Documentation/Validation/2026-10-07/WebCatalog/`; текущий результат — `Documentation/Validation/2026-10-08/CardLargeCell/`.

Ссылка с `#component=…&variant=…&tab=…` восстанавливает выбранный компонент, вариант и раздел. Поиск принимает название, SwiftUI-символ или Figma ID. Раздел спецификации сохраняет исходные названия свойств и отдельно показывает семь проверок, открытые замечания и исторические варианты.

## Состав для распространения

В веб-сборку попадают выбранные PNG/MP4, текстовые документы и SwiftUI-исходники. Файлы Apple Fonts не копируются. Перед публикацией нужно подтвердить состав и права распространения исходных ресурсов библиотеки. Этот локальный каталог не подтверждает готовность всех 128 компонентов.
