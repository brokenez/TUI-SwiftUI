# Системные компоненты Apple: исключение из переноса

Решение пользователя от 9 октября 2026: исключить только системные компоненты Apple из Figma; кастомные компоненты TUI продолжать реализовывать на SwiftUI. Оригинальные файлы Figma не изменять.

Из 128 импортированных наборов 16 имеют исходное имя `system-*`. Эти наборы получают отдельный статус `excluded`, не входят в основной каталог, число реализуемых компонентов и критерий завершения. Остаются 112 наборов для реализации и приёмки. Исключение не означает `complete` или успешно пройденную проверку.

Классификация основана на именах и ID сохранённого импорта `Sources/TUIDesignSystem/Resources/Metadata/figma-components.json`, а не на предположении, что любой компонент навигации или управления является системным. Кастомные `tui-app-bar`, `tui-bottom-sheet`, `tui-tab-bar`, `tui-cell [switch]` и остальные `tui-*` не исключаются этим решением. Android-варианты исключённых системных наборов сохраняются как исходные записи; их реализация и ранее не входила в цель iOS 26.

При сборке новых экранов системные элементы создаются нативными API iOS 26 в приложении-потребителе. Не перерисовывать системные элементы по историческим кадрам Figma и не создавать новые библиотечные обёртки только ради их переноса. Конкретный API выбирать по сценарию и доступным нативным возможностям; не заявлять идентичность системных визуальных вариантов Figma без проверки.

Сохранённые исходные метаданные, прежние реализации и доказательства не удаляются. Уже используемые обёртки остаются для совместимости существующего кода, но не предлагаются резолвером и каталогом как компоненты текущей поставки. Новые экраны используют системные API напрямую. Это решение не разрешает удаление кода или изменение оригинальной библиотеки Figma.

Текущий критерий завершения цели: все 112 оставшихся наборов приняты по полной применимой матрице и прочитанным спецификациям, пакет и оба каталога согласованы с этим объёмом, независимый потребитель проверен, инструкции для Codex и локальная готовность к распространению подтверждены. Решение от 8 октября об исключении дополнительных accessibility-режимов сохраняется. Более ранние формулировки «все 128 complete» являются историческим объёмом и заменяются настоящим решением; исходный импорт по-прежнему содержит 128 наборов.
