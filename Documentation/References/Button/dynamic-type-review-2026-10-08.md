# Button: Dynamic Type и ограничение текста

Полная приёмка набора остаётся **UNVERIFIED**. Реализованы прочитанные требования [iOS scaling, 25085:11908](https://www.figma.com/design/HErJrp1BcNRUFCyg3QccuG/tui-button?node-id=25085-11908), [схемы 25085:11909](https://www.figma.com/design/HErJrp1BcNRUFCyg3QccuG/tui-button?node-id=25085-11909) и [corner cases, 130:282986](https://www.figma.com/design/HErJrp1BcNRUFCyg3QccuG/tui-button?node-id=130-282986). Сохранённые контексты и наблюдаемые аннотации перечислены в [обзоре источника](specification-review-2026-10-08.md).

## Изменения

- UIFontMetrics масштабирует label относительно Body / Subheadline / Footnote без ограничения текста уровнем AX1. Минимальная высота Large/Medium/Small сохраняется: 56/44/30 pt; минимальные вертикальные отступы — 8/6/2 pt.
- Иконка увеличивается один раз на 1.25× при достижении AX1. Дальше сохраняет этот размер: это интерпретация «увеличиваем только в AX1», дополнительные размеры требуют отдельной сверки источника.
- Невмещающийся label отображается в одну строку с фейдом. Использован общий механизм TUIHeaderText; естественная ширина теперь измеряется по самому нативному Text, чтобы короткий Small не фейдился раньше ограничения контейнера.
- Icon-only имеет квадратный контейнер соответствующего размера. Loading сохраняет геометрию normal, включая увеличенный текст. Публичный API сохранён.

## Проверка

[34 теста, 0 ошибок](../../Validation/2026-10-08/ButtonScaling/final-package-test-summary.json), iPhone 17 Pro, iOS 26.4.1: Button — 6, Cell — 7, HeaderCard — 6, HeaderLarge — 15. Помимо 216 пар normal/loading, проверены три размера на Large, AX1 и AX5 при ширине 180 pt, квадратные icon-only и естественная ширина Small относительно независимого UILabel. [Итоговые нативные снимки](../../Validation/2026-10-08/ButtonScaling/Final/manifest.json) включают обе темы и все три уровня текста; Day/AX1 и Day/AX5 просмотрены после исправления преждевременного фейда Small. [Проверенные версии](../../Validation/2026-10-08/ButtonScaling/input-hashes.json) сохранены.

Первый запуск из пяти тестов не выявил ошибку короткого Small; она обнаружена просмотром изображений. Дополнительная проверка UILabel выявила отличие scaledValue от scaledFont; финальная реализация использует UIFontMetrics.scaledFont. Начальные материалы в этой папке проверки исторические; итоговые имеют префикс final и находятся в Final.

Новый расчёт естественной ширины включён только для Button через внутренний параметр TUIHeaderText. Общий режим заполнения Header/Cell сохранён: [132 сопоставимых PNG совпали по всем RGBA-пикселям](../../Validation/2026-10-08/ButtonScaling/header-cell-regression.json) с предыдущей проверкой TypographyConsumers. Промежуточная версия V5 с изменением геометрии двух наборов сохранена отдельно в IntermediateV5; это не итоговые доказательства.

## Ограничения приёмки

Это проверки реализации и регрессии, а не визуальная приёмка всех 147 вариантов Figma. Профиль градиента фейда переиспользован из Header и ещё требует отдельной сверки Button. Ночные bindings, кастомизация иконки, loading motion, skeleton, стеклянное оформление, тени и полное озвучивание остаются непроверенными. Показ Night в renderer не доказывает правильность ночных токенов. Legacy-шрифты сохранены до явного решения о типографике распространяемой библиотеки. Новые результаты не восстанавливают прежнюю приёмку зависимых компонентов автоматически.
