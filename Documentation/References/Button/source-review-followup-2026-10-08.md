## Проверенные источники

Прочитаны контексты общих правил, Mobile, Editorial, построения, состояний, размеров, кастомизации, радиусов, дополнительных возможностей и corner case. Все 26 экспортированных строк Styles просмотрены визуально целиком: заголовок, Primary/Accent, destructive/grayscale, Secondary, Flat, Outline, Glass, Floating и on-light/on-dark. Файлы и контрольные суммы перечислены в [manifest](source-review-followup-manifest-2026-10-08.json). Это чтение схем, не пиксельная приёмка SwiftUI.

В таблице Desktop и Mobile разделены. Outline не имеет iOS/Android примеров; дополнительные fixed on-light/on-dark оформления guide отсутствуют в импортированной iOS-матрице обычного Button и не добавляются к ней молча. iOS pressed меняет заливку без искусственно замедленного перехода. Desktop hover/focus и Android ripple не являются состояниями iOS.

Просмотрены дополнительные схемы 81:48232, 81:48238, 1052:3300, полный Editorial 4:19709 и радиусы 17369:7090. Экспорт 11096:17944 обрезан до полосы 32 pt; он **не** считается полностью просмотренной иллюстрацией. Родительская маскирующая схема 81:48232 читается целиком, вложенные iOS примеры также прочитаны через context 11096:17945. Матрица содержимого 81:48238 использует Desktop-типографику и четыре Desktop-размера: она не доказывает наличие правой иконки в iOS. Реальный iOS API set содержит Text, show-label, show-Icon и два независимых instance swaps Icon / Icon (16).

Свежий контекст set 41658:296906 из-за размера вернул только metadata. Он сохранён как metadata, не выдаётся за полный descendant context. Сверка обнаружила **147 совпадающих iOS ID, свойств и размеров**, без пропущенных ID и отличий: [результат](../../Validation/2026-10-08/ButtonLayout/source-matrix-comparison.json). Отдельно прочитаны полные контексты Large iOS 41658:296907, Medium iOS 41658:296935 и Small iOS 41658:296921. Android 41658:296914 не использовался как источник Medium iOS.

Прочитанная Mobile-спецификация 26:72691 разрешает Medium Hug/Fill. Проверка текущего публичного Button подтвердила поддержку Hug через стандартный `.fixedSize(horizontal: true, vertical: false)`, без новой конфигурации API. Native ImageRenderer сохраняет высоту 44 pt и ширину содержимого для normal/pressed/loading/disabled, с иконкой и без неё, при двух текстах и обеих темах. Fill следует ширине родителя. Проверка живого каталога и её результат находятся в [отчёте](../../Validation/2026-10-08/ButtonLayout/verification-report.md).

## Связанные компоненты и оставшиеся границы

Вложенный loading instance 41658:297261 прочитан: `tui-loader/S/Black`, main 25751:593068. Прямой запрос main отклонён как invalid selection; recursive motion вложенного instance пуст. Полная доступная функциональная спецификация современного Loader прочитана ранее, но не доказывает движение этого отдельного старого глифа. Его длительность/easing остаются **UNVERIFIED**, менять её на современный Loader без источника нельзя.

Для маскирования прочитаны исходный Sensitive Mode set 46866:304541 и полная доступная пиксельная спецификация со схемами: [отдельная запись](../SensitiveMode/specification-reading-2026-10-08.md). Связанный новый particle Sensitive сохранён отдельно, прочитан частично и не подменяет исходную пиксельную матрицу. Новый эффект не реализовывался.

Редакционные внешние ссылки сохранены как первоисточники дополнительных пояснений: [названия действий](https://bureau.ru/bb/soviet/20170418/) и [редакционный пример](https://bureau.ru/bb/soviet/20170502/). Для реализации используются прочитанные правила самого guide, без выдуманных требований из непроверенных внешних материалов.

Полный Button остаётся in-progress: необходимы независимые визуальные пары всех 147 вариантов, точная проверка blur/shadow/fade, окончательное решение по системным/legacy шрифтам и ресурсам, анимации вложенного loading/Skeleton, реализация маскирования и финальные взаимодействия. Чтение доступных схем не означает выполнение этих требований. Расширенная accessibility исключена пользователем. Оригинальные Figma-файлы не изменялись.
