# Button: исходные Variables и Day/Night

Полная приёмка набора остаётся **UNVERIFIED**. Исправлена причина неверных ночных цветов: импорт `figma-button-styles.json` сохранял внешние Variable ID, но TUIButton использовал только разрешённые дневные RGBA.

## Источник соответствий

[Component Set 41658:296906](https://www.figma.com/design/OBPLqL8JDThLuOP8M4JzBL/TUI-Mobile?node-id=41658-296906) содержит 147 применимых вариантов. [Определения Variables этого набора](../../Inventory/2026-10-08/button-variables-mcp.json) ранее прочитаны через MCP. Теперь `search_design_system` с ограничением на опубликованную библиотеку TUI Foundations вернул точные постоянные ключи: [сохранённый ответ MCP](../../Inventory/2026-10-08/button-variable-keys-search-mcp.json).

Каждый из 22 ключей, встречающихся в заливках контейнера и текста Button, сопоставлен по ключу с именем Theme-токена. 228 привязанных paints сохранили исходные дневные RGBA с точностью 0.00001. Совпадение цветов не использовалось для установления идентичности переменных. Дополнительно найден Service/Skeleton; всего в bundled-таблице 23 записи. Скрытый токен тени отсутствует в опубликованном поиске; его параметры берутся из существующего TUIShadow.small и отдельно прочитанной спецификации Foundations.

## Реализация и проверка

TUIButton читает `figma-button-variable-bindings.json` из ресурсов пакета и использует TUIColor.named. Прозрачность разрешённого Theme-токена уже включает alpha: дневная paint.opacity больше не умножает её повторно. Label, иконка и loader получают соответствующий тематический цвет. Floating использует Small shadow-токены, включая нулевые ночные значения; исходная дневная геометрия shadow сохраняется.

[14 тестов, 0 ошибок](../../Validation/2026-10-08/ButtonTheme/package-test-summary.json), iPhone 17 Pro / iOS 26.4.1: ButtonColorTests — 2, ButtonTests — 7, FoundationTokenTests — 5. Независимые проверки подтвердили разрешение ключей, дневные RGBA исходных paints, ночные значения токенов и фактические пиксели заливки/label нативного компонента. Проверены 270 неглассовых отображений в двух темах, включая прозрачные заливки и skeleton, и 198 случаев цвета label; сохранение loading-геометрии и Dynamic Type проверены повторно.

После просмотра схемы Construction исправлены внешние горизонтальные отступы Large/Medium/Small: 16/10/7 pt. В сочетании с padding label это даёт 24/18/11 pt у кнопки только с текстом. При длинном label точное изображение иконки теперь совпадает с её слотом icon-only для всех трёх размеров; отдельный тест сравнивает нативные участки изображения. Масштаб icon-only сохраняет аннотированные отступы AX1 13/7/5 pt.

## Ограничения

Это проверка привязок и пикселей токенов, а не визуальная приёмка всей матрицы Figma. Glass исключён из плоского пиксельного сравнения: material требует реального композиционного фона. Форма, blur теней, шрифты, полный VoiceOver, motion и правила кастомизации не принимаются этими тестами. Проверки complete не обновлялись. Предыдущие отчёты ButtonLoading/ButtonScaling остаются историческими; актуальные доказательства темы находятся в ButtonTheme.

Во время повторного запуска автоматическая проверка разрешений временно отказала из-за лимита Codex; команда тогда не исполнялась. После проверки актуального состояния лимитов повторное разрешение получено, итоговый запуск завершился успешно. Исходные файлы Figma не изменялись.
