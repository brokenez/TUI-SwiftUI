# Расхождение материала on-dark

Проверена текущая сборка с ButtonStyle, small / Default / on-dark, node `30263:433024`, iPhone 17 / iOS 26.4. Снимок: `simulator-on-dark-2026-10-05.png`.

Свежий контекст Figma указывает Background/Overlay Glass On Dark = rgba(255,255,255,0.3) и backdrop blur 30 px. На однородном чёрном фоне ожидаемая заливка вычисляется как 255 × 0.3 = 76.5 (около 77 в 8-bit канале). Это расчёт из параметров дизайна, не измерение отдельного PNG.

В реализации используется native ultraThinMaterial с дополнительной заливкой токеном. Измерение области материала без иконки и края на снимке даёт средний RGB 98.33 / 98.34 / 98.32. Следовательно, материал добавляет собственный цвет; простое совпадение значения Overlay Glass не обеспечивает совпадение результирующего фона.

Точные исходные PNG всех восьми узлов выгружены как `figma-<node>-2026-10-05.png`. У on-dark экспорт отдельного узла уже скомпонован на белом фоне: и угловой пиксель (0,0), и пиксель заливки (15,4) имеют RGBA 255/255/255/255. Поэтому этот PNG нельзя непосредственно сравнивать с кнопкой на чёрной поверхности. Для визуальной приёмки стеклянных вариантов требуется пример Figma с совпадающим фоном, включая неоднородный фон для проверки размытия.

Не заменять материал плоской заливкой только ради совпадения на чёрном фоне: это потеряет требуемое размытие. Исправление ещё не выполнено; visual остаётся pending, компонент — in-progress.
