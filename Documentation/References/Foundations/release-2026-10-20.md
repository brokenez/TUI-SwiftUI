# Foundations: системный SF Pro и подготовка GitHub-поставки

Дата: 20 октября 2026. Платформа: iPhone 17 Pro Simulator, iOS 26.4.1. Область: обычный размер текста, нативный каталог; дополнительные режимы доступности не проверялись по решению пользователя.

## Выполнено

- Публичный продукт `TUI-SwiftUI` добавлен без удаления `TUIDesignSystem`; импорт и существующие потребители совместимы.
- По явному решению пользователя используется системный SF Pro iOS 26. Два старых файла шрифтов вынесены из Resources в игнорируемый локальный архив. Регистрация шрифтов удалена; пакет не распространяет font binaries.
- Сохранены 957 Variables и разрешение alias-графа Primitive/Theme/Platform/State. Неверное имя режима теперь возвращает nil вместо незаметного выбора другой темы. Межколлекционный переход использует объявленный `defaultModeId` источника.
- Все 289 цветов Theme разрешаются в Day/Night с исходными RGBA, включая alpha. Общий separator использует `Border/Normal` вместо системного separator Apple.
- Все 31 документированные роли доступны через `tuiTypography`: системное семейство и вес, исходный размер iOS, автоматический нативный tracking; Rounded для соответствующих Numbers.
- Токены теней Small/Medium/Popup читают Day/Night; Night отключает их. Пять длительностей и шесть cubic-bezier сохранены из спецификации.
- В нативном каталоге добавлен отдельный Foundations: реальные цветовые токены, все роли, Day/Night, выбор кривой и длительности с воспроизведением. Параметры теней показаны как исходные параметры Figma, без заявления о принятом SwiftUI-рендере.

## Что ещё не принято

Foundations целиком **не объявляется complete**. Составные Gradient/Text, Brand, Overlay, Mask и Service/Map не имеют принятой полной реализации; Variables не содержат все позиции и углы. Визуальная приёмка общего shadow renderer и всей шкалы geometry/bindings открыта. Источник Typography содержит противоречие `respectsFontLineHeight`/Body XS (14 против 17); правило по всем ролям остаётся UNVERIFIED. В исходном снимке есть Code/M и Code/S без подтверждённого назначения на прочитанной странице; они не подменены выдуманными ролями.

Исторические компоненты, рисовавшие старым SF, требуют повторной визуальной приёмки с системным SF и проверки собственного tracking. Пользователь выбрал версию шрифта, а не отменил требования к компонентам. Сборка, runtime-тесты и отправка в GitHub не означают, что все 112 кастомных наборов приняты.
