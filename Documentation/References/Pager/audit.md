## Подтверждённый результат

`TUIPager` связан с выбором страницы через Binding и использует 8 исходных SVG. Оригиналы сохранены без изменений. В шаблонных ресурсах автоматически заменён только `fill-opacity="0.12"` на `1`, чтобы прозрачность foundation-токена применялась один раз. Геометрия SVG не изменена. Цвет выбранной точки — `Text/Action`, остальных — `Background/Neutral 3`.

Высота small/medium — 16/20 pt, полные точки — 6/8 pt, интервалы — 7/9 pt. Уменьшенные точки — 4/2 и 6/4 pt внутри исходных слотов 6/8 pt. Компонент скрывается при количестве страниц меньше двух.

Все 10 начальных состояний показаны реальным SwiftUI-кодом на отдельной странице каталога и сверены с экспортами Figma. `matrix-comparison.png` содержит попарное сравнение, `matrix-measurements.json` — измерения. На iPhone 17 Pro iOS 26.4 выбранные точки занимают 18/24 физических пикселя (6/8 pt), внутренний цвет — RGB 66/139/249, как в исходном SVG. Центры совпадают после приведения масштаба; небольшая разница сглаживания по краям не означает побайтовое равенство изображений.

В каталоге подтверждены выбор следующей страницы через Stepper, сдвиг окна на шестой странице и уменьшение правых точек при возврате на пятую. Тёмная тема переключается; цвета берутся из Night-токенов. Приложение и Swift Package собираются, тестовый target компилируется.

Чистая модель окна выполнена отдельным Swift-процессом: проверены последовательности вперёд/назад и 338 349 переходов между страницами для списков длиной 2…100. Во всех случаях выбор остаётся в окне и выделена одна точка. Это не запуск полного iOS-тестового target.

## Что остаётся до complete

1. Проверить дополнительные схемы infinite-scroll / infinite-default-scroll / with-icons и определить их применимость к публичному API.
2. Получить и проверить параметры переходов. `get_motion_context` для схемы `941:2841` вернул `nodes: []`. Придуманной длительности нет: pager меняет конечное состояние без собственной анимации. Нативный контейнер страниц использует стандартное поведение iOS.
3. Проверить жест перелистывания. Изменение Binding через Stepper подтверждено, но попытки горизонтального жеста через текущий инструмент UI не изменили страницу. Жест не считается прошедшим проверку.
4. Полная проверка доступности: регулируемое значение добавлено, скрытые и декоративные точки не дублируют озвучку, но VoiceOver нужно проверить отдельно.

Состояния и начальная матрица проверены; весь компонент ещё не объявлен завершённым.
