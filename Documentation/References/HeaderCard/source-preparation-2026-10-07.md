# Header Card: исходники и текущая реализация

Набор `44217:298609` содержит 18 вариантов, из них 9 iOS. Полные свежие контексты всех девяти сохранены в соседних TXT; ID, свойства, размеры и SHA-256 находятся в `source-preparation-2026-10-07.json`.

Добавлена публичная реализация `TUIHeaderCard` и живой раздел каталога. Header Card переходит в `in-progress`: девять вариантов представлены в API, но полная приёмка ещё не выполнена. Это отдельный компонент, а не вариант Header Large.

Исходная матрица: Accessory None / Avatar / Button / Button Link / Switch, Extended Off / On, skeleton off / on. В матрице только девять фактически существующих сочетаний. Кроме вариантных свойств, исходники содержат title, subtitle, description, badge, hint, caption и дополнительные content slots — их требуется сохранить в API и проверить по руководству.

Отступы: верх 16 pt, низ 12 pt, слева 20 pt; справа 20 pt для None/Link и 16 pt для Avatar/Button/Switch и skeleton. Heading M — SF Pro Display Bold 20, tracking +0.38; subtitle — SF Pro Text Regular 15, tracking −0.24, с дополнительным нижним отступом 2 pt. Шапка имеет собственный padding и должна передаваться контейнеру Card Large без повторного внешнего padding.

Прочитаны мобильные размеры, Dynamic Type и VoiceOver из Header specification (`Vt4htBIFAjKUg8c547G0Ez`); свежие полные контексты сохранены рядом. SVG аватара и hint выгружены из исходного компонента без изменения путей и продублированы в Assets.xcassets. Нативный Switch проверен нажатием в приложении iOS 26.4.1. Caption пока использует системный Medium: визуальное совпадение этого начертания не принято. Требуются итоговая сверка всех указаний руководства, состояний вложенных компонентов, токенов и анимаций, а также полная семантика контента/действий. Контексты и успешная компиляция сами по себе не закрывают приёмку.
