# CardMedium: реальная системная настройка Dynamic Type

Исправлен каталог: размер текста по умолчанию наследуется из системного environment. Меню позволяет выбрать «Системный» либо явные Large/AX1/AX5. Раньше каталог всегда задавал Large, поэтому его программные AX-снимки не доказывали наследование настроек iOS.

Компонент и его публичный API не менялись. Нативные элементы управления каталога разделены на строки List; карточка и счётчики находятся в отдельном доступном контейнере. Это сохраняет область кнопки самой карточки и предотвращает расширение её семантической рамки на всю строку List.

## Выполненная проверка

Устройство: iPhone 17 Pro, arm64 Simulator, iOS 26.4.1, build 23E254a. Существующий Xcode-проект собран схемой TUIDesignSystemCatalogUITests. Полная команда каждого запуска и XCTest-лог сохранены в `Validation/2026-10-08/CardMediumSystemType`.

Системная настройка менялась через штатный `xcrun simctl ui ... content_size`, без launch argument или тестового SwiftUI-переопределения. Чтение настройки до и после каждого изменения сохранено в `system-settings-regression.json`. Исходное значение Large восстановлено.

| Системная категория | Наблюдаемая рамка кнопки, pt | XCTest |
| --- | --- | --- |
| Large | 140 × 140 | Passed |
| AX1 / accessibility-medium | 214.667 × 215 | Passed |
| AX5 / accessibility-extra-extra-extra-large | 214.667 × 214.667 | Passed |

Разница высоты AX1/AX5 0.333 pt — округление геометрии до пикселя при 3x; допуск проверки 0.5 pt. Эталон геометрии — ранее полученные рендеры пакета 420/644 px при 3x, `CardMediumInitial/geometry.json`. Это регрессия наследования системного размера и ограничения AX1, а не новая приёмка шрифтов Figma.

Во всех трёх размерах существует одна кнопка с node ID `11335:41575`, полный label `Title, Subtitle`; настоящее нажатие меняет selected и увеличивает счётчик. Сохранены нативные screenshot, дерево доступности и фактическая рамка. AX1 и AX5-снимки просмотрены: карточка, заголовок и подпись видимы; кнопка и элементы каталога доступны при изменении системного размера.

После изменения контейнера отдельно прошли все три CardMedium UI-теста на Large: физическое нажатие, release вне карточки, selected, disabled, семантический аудит, варианты legacy badge/avatar/skeleton и системный размер. Итог — 3 Passed, 0 Failed в `large-summary.json`; финальная версия проверки размера дополнительно прошла для Large/AX1/AX5, по одному тесту в каждом запуске.

## Неуспешные попытки

Первый контейнер с карточкой прямо в строке List расширял accessibility frame до 370 × 170 pt. Это выявлено тестом, контейнер исправлен, действия повторно проверены. Исходный Failed сохранён в `initial-summary.json` и `large.log`.

Две попытки рассчитывать ожидаемую геометрию через `UIFontMetrics.scaledValue` и `UIFont.preferredFont` были неверным эталоном для существующего кастомного системного шрифта компонента: UIKit возвращает разные размеры для этих API. Логи `accessibility-medium-retry.log` и `accessibility-medium-final.log` сохранены; ожидание заменено независимыми ранее проверенными нативными рендерами. Производственная типографика этим не менялась.

После смены окружения один запуск остановился до тестов: симулятор был Shutdown. Его `system-settings-infrastructure.json` содержит unknown и не доказывает восстановление настройки. После подтверждённого boot выполнен успешный прогон; именно `system-settings-regression.json` доказывает изменение категорий и восстановление Large.

## Оставшаяся приёмка

Accessibility остаётся pending: правила масштабирования всех вложенных компонентов, порядок фокуса и реальное озвучивание VoiceOver ещё не приняты. Specification и visual также pending, включая выбор версии SF Pro. Motion и независимый потребитель не менялись; их существующие доказательства сохраняются. Статус CardMedium — in-progress.
