# Card Medium: источник и требования до реализации

Набор `11335:41574` в TUI Mobile: 41 вариант, из них 21 применим к iOS 26. Все 21 исходных варианта прочитаны через get_design_context; отдельные контексты сохранены рядом с этим документом. SwiftUI API пока не создан, статус остаётся `catalogued`. Этот документ не является визуальной приёмкой.

Спецификация: [tui-card-medium](https://www.figma.com/design/bftkqiWl2LMLIXsAnPKZar/tui-card-medium?node-id=0-1). Первичная выдача MCP показывала только Getting Started. Навигация настоящего файла подтвердила страницы «Дизайн» `0:1` и «Правила» `64:20367`; их структура и отдельные разделы прочитаны через MCP. Ошибка get_design_context на canvas не означает отсутствия дочерних разделов.

Восемь исходных файлов сохранены без изменения в `OriginalAssets/`, с node ID экземпляра и SHA-256 в `OriginalAssets/manifest.json`. В индексе TUI Assets найдены базовые star `1525:528`, note-plus `1134:1192` и subscription-dot-pro `55409:4324`; экземпляры в TUI Mobile имеют свой размер и оформление. Логотипы и маска взяты из конкретного вложенного avatar-stack. В Assets.xcassets эти файлы ещё не подключены: сначала проверить выбранный способ отображения SVG с alpha-mask; документирование байтов не считается реализацией компонента.

До утверждения публичного API дополнительно проверить связанные правила tui-surface и таблицу радиусов/отступов. Для всей распространяемой библиотеки открыт вопрос двух уже включённых файлов Apple Fonts; новые OTF не добавляются. Визуальную точность системной типографики ещё предстоит измерить.
