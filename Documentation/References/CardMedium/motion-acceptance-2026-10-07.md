# Card Medium: приёмка анимации и системного Reduce Motion

Категория motion принята для текущей реализации `TUICardMedium`. Общий ButtonStyle обслуживает все 20 содержательных вариантов; единственный skeleton использует принятый `TUISkeleton`. Это не переводит весь набор в complete: specification, visual, accessibility и integration ещё не закрыты.

## Источник и проверка

- Спецификация `bftkqiWl2LMLIXsAnPKZar`, `84:39831`: iOS scale 0.95, duration 100 ms, productive-standard. Исходный Primitive token задаёт cubic Bézier (0.2, 0, 0.4, 0.9).
- Нативный iPhone 17 Pro, iOS 26.4.1; диагностический CADisplayLink 60 Hz. Проверяется настоящая кнопка из пакета с цветным diagnostic background, без копии ButtonStyle.
- `Validation/2026-10-07/CardMediumMotion/summary.json`: 3 Passed, 0 Failed, 0 Skipped. Успешно исполнены motion-сценарий и оба обычных UI-сценария Card Medium.
- Настоящий Settings Reduce Motion: off → on → off, наблюдение нового значения SwiftUI после foregrounding. При on размер всё время 140 pt, действие работает; после off снова достигается 133 pt и возврат к 140. Исходное системное значение восстановлено.
- Координаты layout-центра и соседнего блока сохраняются. Масштаб изменяется только при разрешённом движении. При отмене release вне карточки действие не вызывается; disabled, selected и выбор badge/avatar/skeleton повторно проверены.

Длительность вычислена по timestamp показанного кадра, а не по моменту получения callback: обратная функция исходной кривой превращает измеренную ширину в фазу, затем регрессия time/phase восстанавливает duration. Для четырёх переходов press/release до и после настройки получено примерно 100 ms, с допуском проверки ±12 ms. Для press измерены две различные промежуточные фазы, для release — пять; ранняя часть press не наблюдалась напрямую. Исходные значения и результаты расчёта сохранены среди Native attachments; числа не заменены константой из реализации.

Независимая сверка реальных пикселей записи подтверждает неподвижный центр и сосед: 77 кадров, максимальное отклонение центра 1 px (0.333 pt при 3x), сосед 0 px. Минимальная ширина по сжатому видео около 95%; отклонение threshold-bounds до двух пикселей учтено явно. Это подтверждение геометрии, не типографики.

## Исправления проверки и границы

Первый native-тест не прошёл из-за двух неверных presentation-координат, не присутствующих на видеозаписи. Затем отсчёт только от первого изменившегося значения неверно сократил duration, а в одном прогоне Settings не изменил ожидаемый переключатель. Проверка перестала продолжать зависимые измерения при ошибке настройки; перед действием обновляет нативный экран и определяет настоящий вложенный UISwitch, если он доступен. Последний неверный результат 50 ms получен при использовании времени callback и нестабильной частоте вызовов. Переход на display timestamp с фиксированной диагностической частотой 60 Hz устранил расхождение; оба времени сохранены отдельно. Неуспешные прогоны не считаются Passed.

Production `TUICardMediumPressStyle`, его curve/duration/scale и скорость системных анимаций в этой работе не менялись. Диагностический экран доступен только в Debug по launch argument; обычные компоненты каталога остаются настоящими View. Проверка выполнена на симуляторе при диагностической частоте 60 Hz; физический экран ProMotion отдельно не измерен. Анимация skeleton наследует актуальную приёмку `References/Skeleton/system-validation-2026-10-06.md`.

## Воспроизведение сверки записи

Из корня репозитория на macOS:

```sh
swift Scripts/extract_native_video_frames.swift Documentation/Validation/2026-10-07/CardMediumMotion/coordinate-probe-native-recording.mp4 /tmp/tui-card-medium-motion-frames 9 11.7
python3 Scripts/verify_card_medium_motion_recording.py --frames /tmp/tui-card-medium-motion-frames --output /tmp/tui-card-medium-motion-geometry.json --start 9 --end 11.7 --scale 3
```

Для анализа PNG требуются Pillow и NumPy. Исходная запись относится к первому прогону датчика координат; её пиксельная проверка самостоятельна и не превращает тот неуспешный тест в успешный. Повторная распаковка сохранённой записи и сверка всех 77 кадров воспроизвели результат. Полный успешный прогон, системные Settings и свежие frame-samples находятся в Native.
