# Skeleton и Skeleton/Text: повторная приёмка 5 октября 2026

Источник: TUI Mobile, наборы `37840:45833` и `37840:45836`. Для обоих наборов Figma возвращает пустые description и documentationLinks: отдельная страница спецификации пока не найдена. Контракт исходных компонентов сохранён в `prototype-contract-2026-10-05.json`; это чтение свойств Plugin API без изменений исходного файла.

## Подтверждённые размеры и цвета

Два кадра Skeleton: 40×40 pt, радиус 4 pt, cornerSmoothing = 0, opacity 1 и 0,5. Используется `TUIRadius.xSmall` и `Service/Skeleton`. Исправлен профиль углов: `.circular` вместо неявного `.continuous`.

Для Skeleton/Text сверены все 13 iOS-вариантов: ширина 92 pt; высоты 36, 24, 20, 18, 16, 14 и 13 pt, полосы и вертикальные отступы сохранены по исходному набору. Android остаётся вне области реализации. Компонент не рисует текст, поэтому замена этих высот текущими типографическими line-height токенами была бы ошибкой. Проверка UIHostingController охватывает 104 сочетания стиля, ширины и Dynamic Type, включая AX5.

Свежие значения Foundations сохранены в `foundation-theme-contract-2026-10-05.json` и `foundation-day-aliases-2026-10-05.json`: Day/iOS — чёрный alpha 3%; Night — белый alpha 10%. Day/Desktop alpha 6% не относится к iOS. Попытка прочитать импортированную переменную непосредственно в Mobile была отклонена Figma в режиме чтения; проверка выполнена через локальные переменные исходного Foundations без импорта.

Все 15 статических вариантов сопоставлены свежим PNG Figma и PNG настоящих SwiftUI-компонентов из XCTest ImageRenderer на iPhone 17 Pro / iOS 26.4.1. Доказательства имеют суффикс `circular-2026-10-05-3x`. Максимальная разница канала — 1 из 255, средняя абсолютная разница — 0,00438–0,01254. Матрицы и измерения сохранены рядом, для текстовых вариантов — в `../SkeletonText`. Статический рендер явно отключает движение через `isAnimating: false`; старые снимки с непрерывным профилем углов не являются текущим эталоном.

## Пропущенная анимация и исправление

`get_motion_context` возвращал `nodes: []`, но это не означает отсутствия прототипа. Прямое чтение `reactions` обнаружило цикл CHANGE_TO между кадрами 1 и 2. На каждом кадре AFTER_TIMEOUT = 0,001 s; SMART_ANIMATE = 0,5 s; cubic-bezier = (0,2; 0; 0,4; 0,9). Все 13 вложенных текстовых экземпляров наследуют реакцию Skeleton.

Реализация использует TimelineView и значения `TUIMotionDuration.slow`, `TUIMotionCurve.productiveStandard`, совпадающие с контрактом. Обе половины цикла используют одну исходную кривую: обычный autoreverse изменил бы кривую обратной половины. Между переходами сохранена исходная задержка. При появлении, смене начального кадра и возобновлении компонент начинает новый цикл. В неактивной/фоновой сцене и при системном Reduce Motion движение останавливается. Компоненты декоративные и скрыты от доступности.

В публичный API добавлен `isAnimating` с default true; false фиксирует выбранный кадр. В каталоге есть переключатель анимации и статические матрицы; показываются живые SwiftUI-компоненты.

Автоматическая проверка независимо вычисляет исходную кривую в 198 точках двух половин цикла для каждого начального кадра, проверяет границы/задержки/повтор и условия остановки. Все 52 теста пакета пройдены; текущие 17 PNG побитно совпадают по RGB с уже измеренными статическими эталонами (`post-motion-render-equivalence-2026-10-05.json`).

Раннер Swift Package не предоставляет UIWindowScene. Эксперимент с тестовым legacy-окном отрисовал компонент, но не обновлял TimelineView; этот эксперимент сохранён отдельно и исключён из рабочего набора тестов. Его результат не используется для приёмки движения. Для проверки добавлена сцена каталога, доступная только в DEBUG при явном аргументе `--tui-skeleton-motion-probe`. Снимок `live-scene-2026-10-05-01.png` подтверждает Scene active и Reduce Motion off. Серия `LiveMotionFrames` содержит 16 кадров: оба живых компонента изменяют Night RGB в диапазоне 13–25, оба статичных контроля постоянно остаются RGB 25. Кадры подтверждают живую пульсацию; точное время перехода по интервалам CLI-снимков не заявляется.
