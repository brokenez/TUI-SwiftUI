# Решение по шрифтам — 20 октября 2026

Пользователь выбрал **системный SF Pro iOS 26** перед публикацией библиотеки на GitHub. Это заменяет прежнее открытое решение о системном/legacy SF.

- Foundations использует публичные системные UIFont/SwiftUI Font: размер и вес из Platform/iOS, SF Pro Rounded для соответствующих ролей Numbers.
- Файлы SF Pro не входят в Swift Package и не публикуются. Прежние локальные файлы сохранены вне Resources в игнорируемом `Documentation/Archives/LocalFonts`.
- Совместимые внутренние вызовы `TUIFigmaTextFont` теперь возвращают системный UIFont; регистрации стороннего font bundle больше нет.
- Референсное значение letterSpacing Figma остаётся в метаданных. Общая iOS-типографика не прибавляет его повторно, согласно спецификации Foundations.
- Исторические legacy PNG сохраняются как история. Это решение не доказывает их попиксельного совпадения с системным SF и не переводит затронутые компоненты в complete. Их устаревшие проверки нужно выполнить заново; критерий приёмки не подменяется старым рендером.

Публичный модуль остаётся `TUIDesignSystem`. Добавлен SPM product `TUI-SwiftUI` без удаления прежнего product, чтобы существующие потребители сохраняли совместимость.
