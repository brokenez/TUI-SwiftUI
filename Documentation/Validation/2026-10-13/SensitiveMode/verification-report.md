# Sensitive Mode: нативная маска и интеграция Button

Реализован общий runtime для исходной пиксельной спецификации: отдельная маска, маскирование целого компонента и скрытые фрагменты нативного Text. `TUIButton.sensitiveText` переиспользует его внутри существующей надписи. **Набор 46866:304541 остаётся in-progress; полная приёмка Button также не завершена.** Apple system-* не переносились, Figma не редактировалась, дополнительные режимы accessibility не разрабатывались.

Read-only MCP повторно подтвердил основной набор [46866:304541](https://www.figma.com/design/OBPLqL8JDThLuOP8M4JzBL/TUI-Mobile?node-id=46866-304541) и пять исходных размеров. ## Реализация

`TUISensitivePixelGrid` строит квадратные плитки цвета скрытого содержимого с псевдослучайной непрозрачностью 0.2–0.4. Число рядов: два до32pt, три с32pt, четыре с48pt, далее плюс один каждые16pt. Seed стабилен; таймеров и придуманной анимации нет. Радиус текста — существующий TUIRadius.xSmall4pt, для целого компонента передаётся его радиус.

Рендерер заменяет только отмеченные глифы. Маскирование всех буквальных вхождений подстроки поддерживает Unicode, повторные суммы, переносы и буквальные `%@`; пустая/отсутствующая подстрока не меняет изображение. Button сохраняет свою исходную типографику, fade, контейнер, variantID, скелетон, загрузку и действие. Старые вызовы API работают без нового параметра.

Найденная проверкой ошибка: `opacity(0)` убирала фактическую реакцию целого скрытого блока на тап. Исправлена маскированием отрисованных пикселей вместо прозрачности control. Повторный consumer-тест подтверждает нажатие всего блока.

В каталоге несколько нативных контролов внутри одной List-строки перекрывали области нажатия; нажатие на Switch открывало Font Size menu. Контролы разнесены по отдельным строкам, стили menu/switch заданы явно. В тесте используется фактическая область нативного переключателя, проверяется его значение1→0→1. AX-frame Canvas в List включает всю строку370×52, поэтому размеры маски измерены по реальным ImageRenderer PNG, а выбор варианта в каталоге — по соответствующему Figma ID. Это не accessibility-аудит.

## Что остаётся открытым

- В Figma основная матрица — дизайнерский placeholder с белыми плитками и blur, Body L содержит изображение; функциональный Guide описывает цвет текста и случайныеopacity. Runtime следует прочитанной функциональной схеме. Свежий источник сохранён, но полные парные визуальные сравнения всех пяти вариантов Day/Night не приняты. Рендеры Native — реальные runtime-доказательства, не исходные Figma PNG.
- Повторный motion MCP возвращает пустые nodes. Это не доказывает отсутствие motion; точная анимация пиксельного варианта остаётся **UNVERIFIED**. Частично прочитанный новый particle-эффект TUI Labs не применяется.
- Variables/bindings и применимость всех режимов источника не подтверждены. Общая типографика и решение о распространении legacy SF шрифтов остаются открытыми в реестре зависимостей Button.
- Полная проверка Button147вариантов, glass/backdrop, Floating shadow, fade и legacy Loader/Skeleton motion остаётся отдельной работой. Данный отчёт принимает проверенные действия маскирования, не все варианты Button.
