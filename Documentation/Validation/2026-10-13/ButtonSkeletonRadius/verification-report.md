# Button skeleton: радиус и исходная ширина

Исходная матрица `41658:296906` содержит три iOS skeleton-варианта: Large `55915:350412` — 323 × 56 pt, радиус 16; Medium `55915:350432` — 323 × 44 pt, радиус 12; Small `55915:350422` — 57 × 30 pt, радиус 100. Значения взяты из сохранённого `figma-button-styles.json` и матрицы, ранее прочитанных вместе с [руководством Button](../../../References/Button/source-review-followup-2026-10-08.md). Исходные Figma-файлы не редактировались.

В `TUIButton` скелетон накладывался одним `RoundedRectangle(cornerRadius: 12)` поверх трёх разных исходных контуров. Теперь он использует уже вычисленный радиус текущего размера, включая разрешённую кастомизацию. Публичный API не изменился. Визуальный референс всех 147 вариантов, типографика и движение skeleton остаются открытыми; этот локальный дефект не переводит весь Button в `complete`.

Точечный `ButtonCustomizationTests/testSkeletonUsesEachSourceSizeCornerRadius` прошёл на iPhone 17 Pro, iOS 26.4.1: **1 passed, 0 failed**. Тест проверяет пиксель у угла для всех трёх радиусов в Day/Night и точные размеры исходных frames. Шесть исходящих из него нативных PNG @3x находятся в [Native](Native/manifest.json); фактические размеры: Large 969 × 168 px, Medium 969 × 132 px, Small 171 × 90 px. Все шесть просмотрены визуально. [Итог XCTest](package-summary.json), [лог](package-tests.log), [версии входов](source-versions.json). Нативный каталог с актуальным пакетом собран: `catalog-build.log` содержит `BUILD SUCCEEDED`.

Первая успешная серия снимков была сделана в intrinsic width, поэтому она не соответствует ширине исходных Figma-вариантов; она сохранена в `InitialIntrinsic`, а итогом служит `Native`. В реестре заменены ссылки только на эти шесть runtime renders. Генератор веб-каталога больше не выбирает для них старые изображения из исторического manifest; остальные Button-снимки не менялись.

Пересобранный локальный веб-каталог отдаёт все шесть новых файлов с HTTP 200 и ожидаемыми SHA256: [результат прямой проверки](web-http-check.json). Общая проверка каталога с HTTP прошла: 112 active sets, 258 вариантов с нативными превью, 586 проверенных assets, 318 копируемых примеров и 2 принятых набора. Локальный сервер запущен на `127.0.0.1:4317`; это не публикация.

Доказано исправление контура и размеров **шести проверенных состояний**. Попарной пиксельной приёмки этих PNG против свежих Figma Day/Night-экспортов, живого UI-прогона skeleton и полного набора Button в этом запуске нет. Статус визуальной категории и набора остаётся `pending`/`in-progress`.
