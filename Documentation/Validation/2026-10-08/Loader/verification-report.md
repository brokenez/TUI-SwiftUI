# Loader: результат этапа

Реализация расширена после чтения функциональной спецификации и всех трёх её схем. См. [прочитанный контракт](../../../References/Loader/implementation-contract-2026-10-08.md). Оригиналы Figma не редактировались.

## API и соответствие

Пять вариантов Size сопоставлены с TUILoaderSize: 12x12 → x12 / 42819:293394; 16x16 → x16 / 42678:293418; 24x24 → x24 / 42819:293395; 32x32 → x32 / 42977:286792; 40x40 → x40 / 43680:292637. Существующий TUILoader(size:) сохранён. Добавлены color, diameter, lineWidth, isAnimating, figmaComponentSetID, figmaNodeID и recommendedMinimumVisibleDuration.

Штатная остановленная поза использует точные экспортированные SVG пакета. Пользовательская и анимированная геометрия использует окружность и скруглённую линию по схеме. Default color — Foundation Brand/T-Bank. Толщина max(1.5, diameter/12), с ограничением максимум диаметром; нечисловые значения заменяются штатными. Исторических iOS 18 вариантов в этой матрице нет.

Родитель управляет появлением/удалением Loader. Для быстрых операций ему следует удерживать состояние загрузки до истечения recommendedMinimumVisibleDuration (500 мс от начала). Сам компонент не может отложить удаление своим родителем. Проверка этого сценария в независимом потребителе ещё не выполнена.

## Выполненные проверки

- Финальный пакет: 5 XCTest passed, package-tests-final.log. Проверены рост/уменьшение линии и обороты в ключевых временах, повтор цикла, нечисловые параметры, источник цвета в обеих темах, все пять базовых ресурсов и настройки геометрии. PackageNative содержит 10 штатных PNG (5 × Day/Night) и 12 пользовательских PNG (18/28/36 × thin/thick × Day/Night). Штатные PNG побайтово совпадают с прямым рендером исходного SVG тем же нативным renderer; это проверка сохранения ресурса, а не свежего независимого экспорта Figma.
- Каталог: BUILD SUCCEEDED, catalog-build.log, после расширения публичного API. Последующая замена alias Background/Accent 1 на точное имя Brand/T-Bank сохраняет тот же RGBA по импортированным Foundations; финальный пакет проверил реальный цвет. Финальная повторная сборка каталога фиксируется отдельно.
- Нативный каталог: 2 UI tests passed, ui-tests-verified.log. Проверены выбор 12/16/32/40, размер 24, переключение цвета Action, произвольный диаметр 28 → 30, толщина 3 → 3.5, остановка, изменение пикселей анимированного компонента между снимками. Для движения сравнивается фиксированная область Loader, не часы/весь экран. NativeUI содержит 7 снимков приложения; снимки просмотрены. UI-прогон использовал до переименования эквивалентный цветовой alias; все остальные строки реализации совпадают.
- Предыдущие два неуспешных UI-прогона сохранены. Причины тестовых ошибок: Stepper имеет составные идентификаторы; границы видимой анимированной дуги меняются и не равны контейнеру. Финальная проверка использует наблюдаемые идентификаторы и измеряет исходную остановленную позу.

## Что не принято

Visual и specification остаются pending: нет свежих независимых reference/runtime сравнений всей матрицы и анимированной геометрии. MCP при повторном чтении Mobile-вариантов вернул транспортный HTTP 403. Прочитанные контексты Guide и сохранённые SVG доступны, но ошибка не превращается в успешную проверку.

Motion остаётся pending: текст/схема задают два оборота за 4 секунды, связанный Lottie — почти один. Нативная функция времени проверена; смена кадров подтверждена в активной сцене. Это не измерение периода по видео. Попытка записи simctl завершилась SimRenderServer error 2, MP4 не получен. Видео и точная временная проверка остаются невыполненными; веб-каталог показывает параметры с этой оговоркой, без подмены нативной записи веб-анимацией.

Расширенная доступность исключена пользователем; не заявляется проверенной. Button использует другой вложенный Loader, и его код не изменён в этом этапе. Полная библиотека не завершена; Loader не получает complete этим отчётом.
