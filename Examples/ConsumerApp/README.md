# Отдельное приложение-потребитель

Откройте `TUIConsumer.xcodeproj`, выберите схему `TUIConsumer` и симулятор iOS 26. Проект подключает публичный продукт `TUIDesignSystem` по локальному пути `../..`.

Пример использует реальные `TUIButtonLike` и `TUIButtonShare`. Like изменяет принадлежащий приложению `@State` через Binding; действие Share открывает нативную шторку. PDF-иконки загружаются из ресурсов пакета. Компоненты, ассеты и токены в приложение не копируются.

Исходные узлы: Like normal/unselected `44290:299175`, normal/selected `44290:299177`; Share secondary/normal `44290:299204`. Пример проверяет интеграцию публичного API. Это не утверждение о готовности этих наборов и не экран, воспроизведённый по отдельному Figma-макету.

После публикации библиотеки локальная зависимость должна заменяться зависимостью от конкретной версии репозитория; адрес репозитория пока не задан.

Пункт «Card Medium из пакета» открывает `App/CardMediumConsumerScreen.swift`: настоящий компонент через публичный API с состоянием приложения, Pro, avatar-stack и notification. Проверены переключение selected, два действия, статическая карточка и нативная шторка. Результат и воспроизведение: [приёмка потребителя](../../Documentation/References/CardMedium/consumer-acceptance-2026-10-07.md). Это закрывает интеграцию компонента; Card Medium ещё проходит specification, визуальную и полную accessibility-приёмку.

Пункт «Header Card из пакета» открывает `App/HeaderCardConsumerScreen.swift`. Девять вариантов, публичное содержимое, собственные обработчики и Binding, disabled, дополнительные ссылки и подсказка проверены в отдельном приложении. [Сопоставление и проверка](../../Documentation/References/HeaderCard/consumer-acceptance-2026-10-07.md). Полная визуальная и спецификационная приёмка Header Card ещё не завершена.

Пункт «Loader из пакета» открывает `App/LoaderConsumerScreen.swift`. Приложение управляет временем видимости: даже мгновенная операция сохраняет индикатор минимум 500 мс от onAppear. Два последовательных запуска проверены UI-тестом; измеренное время и восстановление кнопки подтверждены. [Результат и ограничения измерения](../../Documentation/Validation/2026-10-09/Loader/verification-report.md). Пример не означает complete Loader: геометрия концов анимированной дуги и противоречие источников движения остаются открыты.

Пункт «Textfield из пакета» открывает `App/TextfieldConsumerScreen.swift`: форма с нативным вводом, проверкой пустого значения и отправкой через Return или `TUIButton`. Она использует публичный `TUITextfield`, токены и ресурсы пакета. UI-проверка в Day/Night выявила и помогла исправить зависание при submit; итоговая форма проверяется `CatalogUITests/TextfieldConsumerUITests.swift`. Для прямого запуска передайте `--textfield-consumer`, для Night добавьте `--textfield-dark`. [Результат и ограничения](../../Documentation/Validation/2026-10-09/Textfield/verification-report.md). Это проверка независимой интеграции, а не визуальная приёмка всей спецификации Textfield.
